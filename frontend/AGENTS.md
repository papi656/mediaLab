# AGENTS.md

Notes for coding agents working in `frontend/`.

## ui-sdk

This project uses `@ui-sdk/react` and `@ui-sdk/core`.

Before using ui-sdk:

1. If the `ui-sdk` skill is installed, follow it.
2. Read `node_modules/@ui-sdk/react/docs/llms.txt`.

To build a new component:

3. Search `node_modules/@ui-sdk/react/docs/core.md` by heading for the relevant reference.
4. Read `node_modules/@ui-sdk/react/docs/rendering.md` (next to `core.md`).
